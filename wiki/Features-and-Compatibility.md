# Features and Compatibility

## Core features

- Battery visibility (left/right and case when reported)
- Noise control (Off / Transparency / ANC, model dependent)
- Native earbud EQ preset control (model dependent)
- Low latency game mode toggle
- Wear detection and MPRIS auto-pause/resume hook
- Multipoint switch
- Find My Buds chime controls
- Touch gesture remapping
- Privacy-safe diagnostics export

## Compatibility model

Compatibility in this project is evidence-based:

- **Verified**: maintainer-tested on reference hardware/firmware
- **Community Tested**: reproducible reports from device owners
- **Experimental**: recognized candidate device without sufficient evidence

Unknown or experimental devices may support read-only queries but do not automatically receive full write controls.

## Current verified baseline

- `realme Buds T310` is the current hardware-verified baseline in the main README.

For latest matrix and definitions, see:
- `/docs/devices/compatibility.md`
- `/docs/devices/realme-buds-t310.md`

## Reporting compatibility

The panel can generate a local `.txt` compatibility/problem report.
Reports are reviewed by you before sharing and are never auto-uploaded.
