# realme Buds Wiki

Welcome to the `realme-buds.control` wiki for Omarchy.

This project provides:
- A native Omarchy bar widget for realme earbuds
- A Linux backend with typed APIs
- A CLI for diagnostics and direct device control

It is currently release-candidate quality and hardware-verified primarily on **realme Buds T310**.

## Start here

1. Read [Getting Started](Getting-Started) for requirements, installation, and first run.
2. Use [CLI Quick Reference](CLI-Quick-Reference) for direct commands.
3. Check [Features and Compatibility](Features-and-Compatibility) before testing unsupported models.
4. See [Troubleshooting](Troubleshooting) if controls or battery state are missing.
5. Review [Development](Development) for architecture and test commands.

## Scope and status

- This is an independent open-source project and is not affiliated with realme or OPPO.
- Supported behavior depends on model profile and firmware evidence.
- Compatibility labels in this project are evidence-based (Verified / Community Tested / Experimental).

For deeper technical details, the canonical docs remain under `/docs` in this repository.
